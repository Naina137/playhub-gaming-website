#  PLAYHUB — Your Ultimate Gaming Zone

###  Play • Challenge • Score • Repeat

Welcome to **PLAYHUB**, a browser-based gaming website designed to make casual gaming simple, interactive and enjoyable.

PLAYHUB brings multiple mini-games together in one place with an attractive gaming interface. No complicated installation is required. Open the website, choose a game and start playing!

##  Getting Started

You can run PLAYHUB locally on your computer.

### 1. Clone the repository

```bash
git clone https://github.com/Naina137/playhub-gaming-website.git
```

### 2. Open the project folder

```bash
cd playhub-gaming-website
```

### 3. Run the website

Open `index.html` in your browser.

That's it! You are ready to play.
